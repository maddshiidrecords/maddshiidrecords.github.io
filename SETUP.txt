MADD'SHIID RECORDS - LISTEN PAGE: SETUP (about 5 minutes)
==========================================================

WHAT'S IN THIS ZIP (copy all of it into the ROOT of your repo, same place as index.html)
  index.html                          <- your site, only change: "Listen Now" now goes to listen.html
  listen.html                         <- the retro desktop player (ONE file: HTML + CSS + JS)
  sitemap.xml                         <- listen.html added
  data/sources.json                   <- YOUR list of channels / albums / pinned videos (edit this)
  data/youtube.json                   <- generated by the robot, don't edit by hand
  scripts/update-youtube.mjs          <- the robot's code
  .github/workflows/update-youtube.yml<- tells GitHub to run the robot every 6 hours

STEPS
  1. On github.com open your repo (maddshiidrecords.github.io) > Add file > Upload files.
     Drag in the files/folders above (keep the folders). Commit.
     TIP: if your browser skips the hidden ".github" folder, instead click
     Add file > Create new file, type  .github/workflows/update-youtube.yml  as the name,
     and paste the contents of that file.

  2. Run the robot once so the song list fills in:
     repo > Actions tab > "Update YouTube library" > Run workflow.
     (If GitHub asks you to enable workflows, click the green button.)
     When it finishes (green tick) it commits a filled-in data/youtube.json by itself.

  3. Open https://maddshiidrecords.github.io and press Listen Now.

IF THE ROBOT FAILS (red X in Actions)
  Repo > Settings > Actions > General > Workflow permissions > choose
  "Read and write permissions" > Save, then run it again.

WHAT THE ROBOT DOES
  - Music: reads your 4 Topic channels + your 7 album playlists.
  - Videos: reads @BreedXIVEVO, @HomieLee23VEVO, @maddshiidrecords + the 8 videos already on your site.
  - Without an API key YouTube only shares the LATEST ~15 items per channel, but the robot never
    deletes old ones, so the library grows with every release.
  - To get EVERYTHING (every upload, every album, exact track order) add a free YouTube Data API key:
      Google Cloud Console > new project > enable "YouTube Data API v3" > Credentials > API key.
      Then repo > Settings > Secrets and variables > Actions > New repository secret
      Name: YOUTUBE_API_KEY   Value: (your key). The key stays secret; it is never in your page.

ADDING THINGS LATER
  Edit data/sources.json (on github.com click the file > pencil icon). Examples:
    - new artist video channel:  { "handle": "SomeChannel" }  inside "videoChannels"
    - new album:                 paste the playlist ID (the bit after list=) into "albums"
    - one-off video:             paste its ID into "pinnedVideos"
  Saving that file runs the robot automatically.

NOTES
  - Videos the owner has set to "no embedding" can't play inside any website; the player skips them
    or shows a "Watch on YouTube" button.
  - GitHub pauses scheduled robots on repos with no activity for 60 days. If that happens, open the
    Actions tab and click Enable / Run workflow.
  - Boot screen tip: the "Enter & Play" click is what lets browsers play sound, so music starts
    straight away. Add ?open=videos to the link (listen.html?open=videos) to open a specific app.
